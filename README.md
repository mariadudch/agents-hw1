# Домашнее задание 1 — мини-трекер учебных задач

Вариант А (Новичок). Модель: Claude Opus 5.5 (Effort Medium), 15.11.2026.

Трекер сделан двумя способами в веб-чате: по короткому прямому запросу (tracker-v1.html) и по предварительной спецификации в формате OpenSpec без CLI (tracker-v2.html). В первой версии при проверке нашлась ошибка, её исправленный вариант лежит в tracker-v1-fixed.html.

Чтобы запустить трекер, скачайте нужный HTML-файл и откройте его двойным щелчком в браузере. Ничего устанавливать не нужно.

Спецификация второй попытки находится в файлах proposal.md, spec.md, design.md и tasks.md. Все запросы к модели собраны в prompts.txt. Отчёт с результатами проверок и выводами находится в report.md.
