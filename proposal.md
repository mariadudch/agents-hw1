# Proposal: add-weekly-study-tracker

## Why
Нужен автономный мини-трекер учебных задач на неделю. Он должен показывать, сколько часов запланировано, сколько выполнено и какой процент прогресса. Работает без сети, CDN, внешних библиотек и API-ключей.

## What Changes
- Список задач с полями `id`, `title`, `hours`, `done`.
- Стартовый пример: «Чтение» 2 ч (done=true), «Практика» 4 ч (done=false), «Повторение» 2 ч (done=false).
- Задачи можно добавлять, удалять и отмечать выполненными (done). Каждое действие реально меняет данные.
- Ввод проверяется: название после trim не пустое; часы — число от 0,5 до 24 с шагом 0,5; пустое значение не равно нулю. Ошибка показывается рядом с полем, введённые данные формы сохраняются.
- Итоги: всего часов, выполнено часов, прогресс в %, расчёт без NaN и Infinity.
- Фильтр меняет только видимый список.
- Вёрстка читается на ширине 390 px без горизонтального скролла, у полей и кнопок есть подписи.
- Необязательно: сохранение в localStorage. Если хранилище недоступно, показывается понятное сообщение, приложение продолжает работать в памяти.

## Delivery Variants
- **A:** один файл `tracker-v2.html`, CSS и JavaScript внутри.
- **B:** `index.html`, `styles.css`, `app.mjs`, `domain.mjs`, `tests/acceptance.test.mjs`.

## Out of Scope
- Сервер, аккаунты, синхронизация, внешние API.
- Сторонние библиотеки и CDN.
- Редактирование задач, дедлайны, категории, несколько недель. Ничего сверх перечисленного в требованиях.

## Impact
- Новая capability: `tracker`.
- Документы и реализация делаются разными запросами. В этом запросе только спецификация.
